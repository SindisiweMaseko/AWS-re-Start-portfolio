# Python Scripting Challenge Lab

## Overview

This challenge lab focused on developing a Python script in a Linux cloud environment using an Amazon EC2 instance. The goal was to practice Python scripting, SSH connectivity, and file handling while working on a remote Linux server.

The script generates all **prime numbers between 1 and 250** and saves the results into a file called **results.txt**.

---

# Lab Environment

The lab was performed using the following tools and technologies:

* Amazon EC2 Linux Host
* Python 3
* SSH connection using PuTTY / Terminal
* Linux command line

---

# Objectives

The objective of this lab was to:

* Connect to a Linux EC2 instance using SSH
* Create and run a Python script
* Generate prime numbers between **1 and 250**
* Store the results in a file called **results.txt**
* Test and verify the output

# Creating the Python Script

A Python script was created on the Linux server to generate prime numbers.

File name:

```
prime_numbers.py
```

Python code:

```
def is_prime(num):
    if num < 2:
        return False

    for i in range(2, int(num ** 0.5) + 1):
        if num % i == 0:
            return False

    return True


with open("results.txt", "w") as file:
    for number in range(1, 251):
        if is_prime(number):
            file.write(str(number) + "\n")

print("Prime numbers between 1 and 250 have been saved to results.txt")
```
