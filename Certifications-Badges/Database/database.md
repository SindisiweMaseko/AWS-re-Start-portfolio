### AWS SimuLearn: Databases in Practice 
I recently completed the AWS SimuLearn: Databases in Practice course, a hands‑on learning experience focused on real‑world database operations in the AWS cloud. 

###  What the Course Is About
This SimuLearn module teaches the fundamentals of working with Amazon RDS through guided, scenario‑based tasks. Instead of theory alone, it emphasizes practical cloud skills such as deploying databases, configuring high‑availability setups, scaling with replicas, and troubleshooting real issues in a live AWS environment.
