# AWS SimuLearn: Core Security Concepts

## Overview
Completed the AWS SimuLearn lab focused on implementing secure IAM access controls using the principle of least privilege.

## What I Implemented
- Created an IAM group: **SupportEngineers**
- Added IAM users to the group
- Attached AWS managed policies:
  - **AmazonEC2ReadOnlyAccess**
  - **AmazonRDSReadOnlyAccess**

## Key Outcomes
- Allowed read-only access to EC2 and RDS
- Prevented destructive actions by 'instance termination'
- Strengthened understanding of IAM groups, policies and secure access design in AWS
