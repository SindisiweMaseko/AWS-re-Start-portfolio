# AWS SimuLearn – System in the Cloud
I recently completed the AWS SimuLearn System in the Cloud module, where I learned the basics of how cloud systems work using Linux and Amazon EFS. 

This hands‑on lab helped me understand how servers share files across multiple availability zones, how to mount an EFS file system to EC2 instances, and how Linux processes and commands support cloud environments. 

This experience strengthened my foundation in cloud architecture and boosted my confidence as a student starting out in the tech space.
